# Imposter Game 🎭

A fun multiplayer party game where players try to identify the **Imposter** among them.

Players can choose how many people are playing, and the game randomly assigns roles. Everyone except one player receives the same secret word, while the Imposter either receives a blank word or is directly told that they are the Imposter.

### How It Works

1. Select the number of players.
2. The game randomly selects one player as the Imposter.
3. Each player privately reveals their role and word.
4. Most players receive the same secret word.
5. The Imposter receives a blank word or an Imposter notification.
6. Players discuss, give clues, and try to figure out who the Imposter is.
7. The group votes for who they think the Imposter is.

### Features

* 🎮 Support for multiple players
* 🎲 Random Imposter selection
* 🔐 Private role and word reveals
* 🧠 Same-word assignment for regular players
* 🎭 Imposter-specific role assignment
* ✨ Clean and interactive UI
* 📱 Responsive design for mobile and desktop
* 🔄 New game/replay functionality

### Goal

The goal was to build a simple but engaging party game while focusing on a smooth user experience, intuitive interactions, and keeping each player's role and word private during the game.

This project also explores state management, randomization, conditional rendering, responsive UI design, and creating an interactive game flow from start to finish.
